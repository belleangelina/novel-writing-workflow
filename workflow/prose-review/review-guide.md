# 逐句文风审查指南

## 1. 审查依据

逐句文风审查判断“是否符合本书”，依据已确认的 `style/guide.md`；本文件只规定检查方法。相邻的已终审正文可以帮助判断人物声音，但不能覆盖明确的文风规则。

外部检测器、语言模型评分和自动标注只提供实验信号。分数高低不能单独构成 `PASS`、`REVISE` 或正文写入依据。

## 2. 先找集中倾向，不追单句标签

一句话可以准确、漂亮、对称或具有镜头感，这些都不是天然问题。需要检查的是同一场景是否连续出现多种过度设计信号，使文本显得每句话都完成了预定功能。

重点检查：

1. **过度功能化的细节**：物件、气味、声响、视线和小动作是否都恰好在暗示情绪、交代环境或推动情节。删掉细节后若人物、空间和节奏都不受影响，应检查它是否只是为了制造“生活感”。
2. **镜头调度式观察**：叙述是否按入口、陈设、人物局部、表情和关键物件依次扫过，而不是跟随视角人物当下真正关心的内容。
3. **对白过度对称**：双方是否长期保持一问一答、句长相近、针锋相对或每句都准确承接。真实交流允许概括、遗漏、错位、沉默和信息量不相等。
4. **心理解释闭合**：人物是否总能把抗拒、选择和下一步行动解释完整。想法和行动可以不一致，也不必由叙述替读者总结矛盾。
5. **动作总在表意**：每个起身、停顿、移开视线或拿放物品是否都承担潜台词。普通动作可以只是维持场景连续性的普通动作。
6. **句式和段落分布过稳**：短句、长句、独立短段和叙述密度是否呈现可预测的循环。调整必须服从语义和阅读节奏，不能为了制造随机性故意写坏句子。
7. **过度概括和平滑**：叙述是否快速替读者整理关系、动机和后果，导致每段都没有多余、迟疑或未解决之处。
8. **刻意的“真人细节”**：走错路、衣服穿反、翻记录等细节若只为证明人物像真人，而不来自人物注意力或场景需要，通常会显得更加设计化。

## 3. 审查步骤

1. 先从头到尾连读场景，不修改，记录确切的不自然位置。
2. 将问题归入人物声音、信息状态、对白连接、心理解释、动作与空间、细节密度、句段节奏等类别。
3. 判断它是单句问题，还是多个信号集中形成的分布问题。没有集中倾向时，不因主观偏好重写。
4. 每次修改一个可以描述清楚的因素，保留其他内容，检查人物、因果、空间和衔接。
5. 有效因素要做两两及必要的三项组合。组合结果可能与单项结果方向相反，不能线性推断。
6. 选出候选版本后重新从头连读。只有文学质量和作品规则都合格，才允许写入正式正文。
7. 修改后执行章内逻辑、逐句文风和跨章衔接的定向回归。

## 4. 使用外部检测器时

外部检测是受控实验，不是创作目标。必须：

- 记录日期、工具、模型或扫描模式、精确输入边界和基线结果；
- 将文本划分为可独立替换的区域，先测单一因素；
- 记录所有结果，包括失败和反直觉结果；
- 对有效因素做组合，不能只保留最低分截图；
- 不使用不可见字符、乱码、故意错别字、字符插空格或无意义污染；
- 不把未达标或文学质量更差的版本写入正式正文；
- 达标后用完全相同的文本至少复测一次；
- 检查最终文本与未修改区域、相邻场景和后续伏笔的衔接；
- 检测器版本或模式改变后，不把旧分数当成可直接复现的事实。

局部高风险句只说明工具在当前组合下关注它。追着标签删除句子可能使整体分数更差，也可能损害文本；必须通过真实对照验证。

## 5. 通过标准

逐句审查可以判定 `REVISE` 的依据仍然是可定位的不自然表达、人物声音错误、信息或因果错误、视角越界、重复解释，或明确违反已确认文风。检测分数、所谓“更像真人”或另一种写法可能更漂亮，都不能单独阻止通过。

审查完成时至少能回答：

1. 这一场景有没有连续使用功能相似的细节或动作？
2. 人物是不是把自己的动机解释得过于完整？
3. 对白是否整齐到像为下一句预先搭好台阶？
4. 叙述顺序是否像镜头清单，而不是人物注意力？
5. 删改后人物性格、信息状态、空间连续性和叙事张力是否仍然成立？
