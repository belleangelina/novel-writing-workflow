# 文风实验记录

本目录保存非规范性的工具实验和对照结果。实验文件不能替代 `style/guide.md`，也不能仅凭分数要求修改正文。

每份记录至少包含：

- 日期、对象、文本边界和实验目标；
- 工具、模型或扫描模式；
- 不可使用的技术作弊手段；
- 基线文本来源和精确结果；
- 因素定义；
- 包括失败版本在内的完整矩阵；
- 最低分版本及至少一次原样复测；
- 文学质量、人物、逻辑和衔接检查；
- 能推广的方法与不能推广的工具特定结论；
- 正式正文是否修改，以及最终 Git 状态。

复制 `record-template.md` 后再记录具体实验。推荐文件名：`YYYY-MM-DD-章节或范围-工具.md`。
