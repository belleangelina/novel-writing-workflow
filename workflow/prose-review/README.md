# 逐句文风审查资料

本目录保存逐句文风工作的通用方法和可追溯实验。它与作品文风指南分工如下。

| 层级 | 位置 | 作用 | 权威性 |
|---|---|---|---|
| 作品文风 | `style/guide.md` | 规定本书最终采用什么写法 | 已确认后是文风判断的唯一作品级标准 |
| 审查方法 | `workflow/prose-review/review-guide.md` | 规定怎样发现、定位和验证文风问题 | 只提供方法，不替作品决定文风 |
| 实验记录 | `workflow/prose-review/experiments/` | 保存检测工具、对照版本、分数和复测结果 | 只作为证据，不自动产生文风规则 |

三层发生冲突时，先服从已确认的 `style/guide.md`。审查指南不能把一种写法直接规定为错误；实验结果也不能单独触发正文修改或审查通过。

创作或审查正文时读取前两层。只有当前任务涉及既有实验、外部检测器或某项规则的来源追溯时，才读取相关实验记录，不扫描无关实验。

实验中确认的通用认识可以回写审查指南；与作品长期取向一致、且经用户确认的部分可以回写文风指南。回写后仍保留原始实验记录，避免把工具结论伪装成不证自明的文学规则。
